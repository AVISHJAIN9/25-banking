# Frequently Asked Questions: AegisBank Ledger & Digital Banking

### 1. What is AegisBank Ledger & Digital Banking?
Digital banking portal with double-entry balance verification, transaction histories, and OAuth.

### 2. What technology stack does it use?
Built with Node.js (Express, MongoDB Atlas), Vanilla JS / CSS3.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/25-banking/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
