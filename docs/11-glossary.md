# Banking & Technical Glossary

- **Double-Entry Bookkeeping**: An accounting system where every transaction requires both a debit and a credit entry.
- **General Ledger**: The complete record of all financial transactions across an institution's lifetime.
- **IDOR**: Insecure Direct Object Reference, a vulnerability where an attacker accesses unauthorized data by manipulating an identifier.
- **ACID**: Atomicity, Consistency, Isolation, Durability; database transaction properties guaranteeing valid data.
- **TTL Index**: Time-To-Live index in MongoDB that automatically removes expired documents after a set duration.
